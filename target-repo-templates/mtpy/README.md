# mtpy

Python CLI distribution repository for merge.tonic (`merge-tonic`).

## Canonical documentation

- Canonical component docs: https://github.com/mergetonic/common/wiki/Core-Python-mergetonic
- Wiki home: https://github.com/mergetonic/common/wiki
- Docs are authored in mergetonic/common and published centrally to wiki.

## Source of truth

This repository is mirrored from `mergetonic/common`.

## How to contribute

Open pull requests against `mergetonic/common`. Do not push directly to this repo.

## What is target-owned

This repository keeps target-specific docs and workflows from `target-repo-templates/mtpy`.
